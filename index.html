数据结构

公共字段
中文名称后台英文作用结构 / 注意

父级 IDparent_id把节点挂到对应赛程或分站。用于和赛程管理的父级对象建立关系。
运动类型 IDsport_id标识数据属于 F1。当前 F1 使用固定运动类型。

扩展字段extra保存主表之外的天气、圈速颜色、计时段、轮胎和限制次数。按车手 ID 组织车手扩展数据；天气是节点级对象。

02 · 车手扩展

车手详情

上一圈 / 最快圈（last_lap_time / fastest_lap_time）：同赛果主表，并按颜色字段说明展示全场最快、个人最快、慢于上一圈、损失大量时间和进站 / 出站。

当前轮胎（tire_info）：当前最后一段轮胎配方和起止圈；最后一段没有结束圈时按数据源已有范围展示。

进站次数（pitstop_count）：以维修区进站记录为准；没有进站记录就不虚构次数。

总圈数（total_laps）：轮胎历史各段圈数合计，用来检查轮胎策略是否覆盖比赛圈次。

超出赛道限制（track_limits）：该车号关联的限制事件数量，不代表处罚结果。

计时段 / 小计时段（sectors / mini_sectors_data）：计时段显示两行成绩，小计时段只显示有数据的色点，不把缺失值显示成 0.000。

03 · 轮胎历史

轮胎策略表

轮胎策略（圈次）（tire_history）：按进站前后分段列出配方和覆盖圈次，便于还原策略变化。

进站（pitstop_count）：每位车手对应的维修区记录数。

总圈数（total_laps）：所有轮胎段圈数合计。轮胎年龄等实时胎龄字段不采集。

当前轮胎（tire_info）：该车手最后一段轮胎，作为赛果主表的当前状态。

轮胎历史是按车手合并的一行，避免同一车手被拆成多行；没有数据的节点显示为空。

查看语言 / 条数—切换英文、中文或双语，并控制显示条数。页面支持英文和中文两行展示、全部或最近记录。
05 · 年度排名

年度排名

官网快照

名次（position）：官网排名快照中的赛季累计名次。

车手 / 车队 / 国籍 / 缩写：官网快照的身份信息和展示字段。

后台车手 ID / 后台车队 ID（_id / teamuid）：仍使用后台映射表，不使用官网内部 ID。

积分（points）：官网排名快照提供的赛季累计积分。

排名数据每周一 08:00（北京时间）自动同步，也可点击人工同步；失败时保留上一次成功快照并报警。

06 · 实时推送

实时推送

覆盖当前快照

数据内容：实时页沿用赛程管理的字段命名和映射规则，包含赛果、圈速、计时段、轮胎、天气和赛会消息。

更新方式：打开实时更新后持续拉取当前会话，页面用新快照覆盖旧快照。

存储方式：实时数据不写入赛后缓存，不会覆盖赛程管理中已保存的节点数据。

缺失字段：实时接口没有返回的字段直接留空，不使用其他节点的 Q3、上一圈或颜色数据补齐。

07 · 比赛术语

比赛术语

业务解释
英文术语（消息内容，不是字段）中文含义在页面中的作用
SESSION STARTED / RACE START比赛开始 / 比赛开始标记练习、排位或比赛正式进入计时阶段。
SESSION RESUMED / RACE WILL RESUME比赛继续 / 比赛将继续红旗或暂停后恢复运行，不代表重新开始一场比赛。
SESSION ABORTED / RACE SUSPENDED比赛中止 / 比赛暂停说明当前流程被中断；消息仍保留在赛会记录中。
TRACK CLEAR / CLEAR赛道清理完毕表示事故处理或障碍清理完成，通常与旗语恢复配合出现。
VSC DEPLOYED / VSC ENDING虚拟安全车已出动 / 即将结束全场受虚拟安全车速度规则约束，页面只记录赛会状态。
SAFETY CAR DEPLOYED / SAFETY CAR IN THIS LAP安全车出动 / 安全车本圈结束实际安全车带队控速；“本圈结束”表示将驶回维修区。
YELLOW FLAG / DOUBLE YELLOW黄旗 / 双黄旗事故或危险区域的警示；双黄旗代表更高等级的减速和禁止超车要求。
GREEN FLAG / RED FLAG绿旗 / 红旗绿旗表示赛道恢复可正常行驶；红旗表示会话暂停，车手需减速回到维修区。
BLUE FLAG / BLACK AND WHITE FLAG蓝旗 / 黑白旗蓝旗通常提示被套圈车让行；黑白旗是对车手行为的正式警告。
PIT LANE OPEN / PIT LANE CLOSED维修区开放 / 关闭说明赛车是否可以通过维修区参与发车或比赛流程。
PIT EXIT OPEN / PIT EXIT CLOSED维修区出口开放 / 关闭控制赛车能否从维修区出口驶入赛道。
TRACK LIMITS / LAP DELETED超出赛道限制 / 单圈成绩取消前者计入车手关联事件次数；后者表示该圈成绩不再用于排名或最快圈。
MOVING UNDER BRAKING刹车区变线车手在制动区域改变行驶线路，作为可能违规的赛会消息记录。
IMPEDING / CAUSING A COLLISION阻挡其他车手 / 引发碰撞记录车手行为被赛事干事关注，是否处罚要看后续调查结果。
FORCING ANOTHER DRIVER OFF THE TRACK迫使对手离开赛道描述攻防中的具体行为，不等同于已经判罚。
UNSAFE RELEASE / UNSAFE RE-JOIN不安全释放 / 不安全回场分别对应维修区放车和离开赛道后回到赛道时造成危险的情况。
SPEEDING IN THE PIT LANE / FALSE START维修区超速 / 抢跑记录违反速度限制或发车程序的事件，处罚以干事决定为准。
UNDER INVESTIGATION / WILL BE INVESTIGATED AFTER THE SESSION调查中 / 将会赛后调查说明事件尚未有最终结论；不能直接把消息当作已处罚。
NO FURTHER ACTION / REVIEWED不进一步调查 / 经审核表示干事查看后不再采取措施，保留原始消息用于审计。
RISK OF RAIN FOR xx未来 xx 分钟降雨概率按中文语序显示为“正赛降雨概率是 30%”这类消息，不把概率误写成温度或当前降雨。
WET TRACK / TRACK SURFACE SLIPPERY赛道湿滑 / 路面湿滑描述赛道抓地力状态，不代表每辆车都装了湿地胎。
LOW GRIP CONDITIONS / NORMAL GRIP CONDITIONS赛道抓地力不足 / 赛道抓地条件正常描述低抓地力或正常抓地力规则的当前状态。
紫色 / 绿色 / 黄色 / 红色 / 蓝色计时色全场最快 / 个人最快 / 不如上一圈 / 损失大量时间 / 进站或出站颜色字段用于解释圈速、计时段和小计时段的状态；灰色表示没有有效数据。
Finished / DNF / DNS / DSQ完成 / 退赛事件 / 未发车 / 取消资格状态来源于数据源事件；DNF 是事件，不能直接等同于 NC。
NC / Not Classified未获正式排名仅正赛和冲刺赛按冠军实际圈数 × 90% 向下取整判断；DSQ、DNS 优先级更高。
参考：FIA Formula One Sporting Regulations、OpenF1 数据字段文档。页面中文是本地词典优先、缺失时机器翻译。
核对原则车号是车手匹配主键；后台 ID 来自映射；没有数据就留空；NC 只在正赛和冲刺赛按 90% 圈数规则计算；所有时间按“分:秒.毫秒”展示。
